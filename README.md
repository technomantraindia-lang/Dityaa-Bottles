> **Reliable Polymers for Life-Saving Products**  
> Premium primary pharmaceutical packaging website manufactured in certified Class 100,000 cleanrooms in Vadodara, Gujarat, India.

---

## 🏭 Overview
**Dityaa Bottles** is a primary pharmaceutical container manufacturer operating dual state-of-the-art production facilities:
* **Unit-1 (Ranoli, Vadodara)**: High-speed single-stage Japanese Nissei ASB ISBM machines for amber & crystal-clear PET oral liquid bottles and syrup containers.
* **Unit-2 (Padra, Vadodara)**: Automated extrusion blow moulding (EBM) lines for USP <671> moisture-barrier HDPE solid-dosage pill packers, powder jars, and child-resistant closures (CRC).

## 📦 Deployment & Setup
To run locally:
```bash
# Clone the repository
git clone https://github.com/technomantraindia-lang/Dityaa-Bottles.git

# Navigate to project folder
cd Dityaa-Bottles

# Open index.html in any modern browser
```
Or serve via any static web server:
```bash
npx serve .
# or
python -m http.server 8000
```
